# Idomizrachi-bringg Dev-tools

## How do I install these formulae?

`brew install idomizrachi-bringg/dev-tools/<formula>`

Or `brew tap idomizrachi-bringg/dev-tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "idomizrachi-bringg/dev-tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
